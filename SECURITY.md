# Security policy

DraftYak is in early development and has no releases yet.

## Reporting a vulnerability

Report a suspected vulnerability privately, through GitHub's private vulnerability reporting:
https://github.com/draftyak/draftyak/security/advisories/new

Please don't open a public issue or pull request about it. Include what you found, how to reproduce it, and the commit or branch you tested. Don't include real messages or other personal data.

The full policy, with scope, response times and safe harbor, will be published in milestone M11, before the first release.
